# RemoteJob AI

RemoteJob AI is a production-oriented remote job aggregation and job management platform.

## MVP included

- User profile management
- Multi-source remote job fetching
- ATS resume analysis
- Job filters
- Application tracking
- Responsive dashboard

## Stack

- Python 3.12+
- Flask
- SQLite
- SQLAlchemy
- Bootstrap 5
- APScheduler

## Run

1. python -m venv .venv
2. .venv\Scripts\activate
3. pip install -r requirements.txt
4. copy .env.example .env
5. python app.py

Then open http://127.0.0.1:5000/
